# Privacy policy

KohdaLab IV does not collect telemetry, upload measurement data, contact an
analytics service or automatically check for updates. Measurement CSV files,
run metadata, settings and diagnostic output are stored on the local computer.
Users choose whether to copy, export, share or delete them.

Instrument communication is initiated by the user through selected USB/GPIB
resources or an installed official VISA runtime. A VISA resource may refer to
a network instrument; that communication follows the resource chosen by the
operator. The application does not scan network hosts for instruments.
Manufacturer runtimes are installed separately and are subject to their own
vendor privacy policies and configuration.

Windows USB setup enumerates connected USB devices locally and can install the
Windows inbox WinUSB assignment only when explicitly invoked with administrator
approval. It does not download manufacturer firmware. Windows itself may use
Windows Update, SmartScreen or certificate validation services according to the
computer's operating-system settings; these services are outside this app.

Downloading releases or reporting issues on GitHub uses GitHub's services and
[privacy policy](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
Do not put confidential measurement data or identifying instrument information
in a public issue. Build-time package downloads and future signing requests are
maintainer operations, not end-user telemetry.

# プライバシーポリシー

KohdaLab IV はテレメトリーを収集せず、測定データをアップロードせず、分析サービスへ
接続せず、更新を自動確認しません。測定 CSV、実行メタデータ、設定、診断出力はローカル
コンピューターに保存されます。これらをコピー、エクスポート、共有、削除するかは利用者が
選択します。

計測器通信は、利用者が選択した USB/GPIB リソースまたはインストール済みの公式 VISA
ランタイムを介して開始されます。VISA リソースがネットワーク計測器を指す場合、その通信は
操作者が選んだリソースに従います。アプリケーションが計測器を求めてネットワークホストを
スキャンすることはありません。メーカーランタイムは別途インストールされ、各ベンダーの
プライバシーポリシーと設定に従います。

Windows USB セットアップは接続済み USB デバイスをローカルで列挙し、管理者承認を伴って
明示的に起動された場合にだけ Windows 標準の WinUSB 割り当てをインストールできます。
メーカーのファームウェアをダウンロードすることはありません。Windows Update、SmartScreen、
証明書検証サービスの利用はコンピューターの OS 設定に従い、本アプリの対象外です。

GitHub からのリリース取得または問題報告には GitHub のサービスおよび
[プライバシーポリシー](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)
が適用されます。機密の測定データや識別可能な計測器情報を公開 Issue に書かないでください。
ビルド時のパッケージ取得と将来の署名要求は保守者の作業であり、エンドユーザーの
テレメトリーではありません。
