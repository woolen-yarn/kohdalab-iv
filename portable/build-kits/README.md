# Portable source build kits

These archives contain the project snapshot, native dependency sources and
platform launchers needed to rebuild the portable desktop application.

- macOS: extract the macos-release-build-kit ZIP and run Build-macOS.command.
- Windows: extract the windows-release-build-kit ZIP and run Build-Windows.cmd.

Read the English README.txt inside each kit before building. These kits are
for build machines, not instrument users. The finished portable app needs no
Python installation. See docs/portable_release.md in the project snapshot.
SHA256SUMS.txt verifies these exact kits. Nested build-kit archives are excluded.
