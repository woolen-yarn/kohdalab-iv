# Portable v0.2.3 distribution

These are the preserved final macOS arm64 and Windows x64 portable archives.
The Windows archive was supplied by the user after successful operation on the
instrument PC. The application archives are kept unchanged during publication.
SHA256SUMS.txt verifies all published application and build-kit archives.

Public downloads:
- https://github.com/Kohdalab/kohdalab-iv/releases/tag/portable-v0.2.3
- https://github.com/woolen-yarn/kohdalab-iv/releases/tag/portable-v0.2.3

Build kits are also retained in portable/build-kits. See docs/portable_release.md.
Old development builds, generated test results and caches can be regenerated
and are excluded from the project. Source code, dependency sources, licenses,
example configurations and final distribution checksums are retained.
